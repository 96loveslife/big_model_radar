**1. "Agent Skill" 标准化竞赛进入白热化。** Trending 中连续出现的 `openwork`（+806）、`last30days-skill`（+658）、`reverse-skill`（+335）几乎都是同一个范式：一个轻量、技能化、可挂载到 Claude Code / Codex / Hermes / OpenCode 等多客户端的"技能包"。这表明 Agent 生态已从"框架之争"进化到"技能市场之争"——谁拥有更多更专业的 Skill，谁就能占领 Agent 装机量。

**4. 国产开源加速入场。** alibaba/zvec、HKUDS/nanobot & Vibe-Trading、shareAI-lab/learn-claude-code、datawhalechina/hello-agents、bojieli/ai-agent-book 等中文社区项目在 AI Agent、RAG 教程、LLM 框架维度密集出现，呈现出"中文教程 + Agent 实战 + 基础设施"的三层生态。
