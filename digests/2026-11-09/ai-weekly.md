## 4. 开源趋势

### 1. 从模型封装转向 Agent Runtime

竞争重心已由 CLI 外观和模型调用能力，转移至：

- 会话与任务状态机；
- 后台进程和事件系统；
- 多 Agent 调度；
- 工具调用及上下文管理；
- 权限、费用和可观测性。

### 2. MCP、Skills、ACP、Code Mode 走向分层协作

本周没有出现单一协议“赢家”。更明显的趋势是：

- MCP 负责外部工具接入；
- Skills 负责可复用工作流和领域知识；
- ACP 负责 Agent 间或客户端—Agent 协作；
- Code Mode 通过程序化方式降低大量工具 schema 的上下文成本。

### 3. 上下文预算成为架构约束

工具全量注入、目录膨胀、长会话压缩和多代理 token 成本，使“上下文即系统资源”成为共识。增量工具目录、按需加载、摘要与缓存将持续升温。

### 4. 安全修复优先于大型功能发布

本周高频安全议题包括：

- DNS 重绑定与 Git 参数绕过；
- 凭据及秘密文件外发；
- 破坏性 Shell 命令漏检；
- MCP 服务权限过大；
- 子代理继承父级权限；
- Agent 重复执行和费用失控。

### 5. 跨平台工程成为“隐藏刚需”

Windows、macOS、Wayland、SSH、中文 IME、Unicode、桌面端及 IDE 集成问题贯穿多个项目。短期内这些基础兼容性的价值可能高于新增一个 Agent 角色。

### 6. 高频 Preview 与快速重构并存

Codex Alpha、Gemini Preview、Copilot CLI 补丁号和 jcode Preview 密集出现。生态因此具备高交付速度，但也伴随回归、版本碎片化和升级成本。
