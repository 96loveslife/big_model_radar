## 1. 本周要闻

### 1.1 多 Agent 从“能并行”进入“可控、可恢复”阶段
**日期：11/16—11/23**

Claude Code、Gemini CLI、OpenCode、jcode、pi 等集中推进子代理、前台编排、任务取消和状态同步。社区关注点已从“能否调用多个 Agent”转向：

- 父任务与子任务能否独立取消；
- 子代理超时、递归调用和失控循环如何处理；
- 状态、费用、重试和终止原因能否被完整观测；
- 切换会话或断线后，后台任务能否恢复。

这一趋势表明，多 Agent 的核心难点已经从调度能力转移到**生命周期管理和故障语义**。

### 1.2 Windows、WSL、Wayland 成为可靠性短板
**日期：11/16—11/23**

Claude Code、Codex、Gemini CLI、OpenCode、pi 和 jcode 均出现 Windows、PowerShell、WSL、Wayland 或 MSIX 安装相关问题，覆盖路径解析、上传失败、会话读取、UI 卡死、Shell 行为差异和安装升级回归。

跨平台支持已经普遍进入产品路线，但“支持某平台”尚不等于“与 macOS/Linux 行为一致”。非主流开发环境仍是本周最集中的生产可用性风险之一。

### 1.3 MCP 快速普及，但生命周期与互操作问题暴露

MCP 已成为主流 CLI 的共同基础设施，本周相关问题集中在：

- 沙箱下的凭据隔离；
- ACP、A2A、MCP Tasks 等协议之间的边界。

行业已从“是否支持 MCP”进入“能否建立稳定、可迁移的插件运行时”。
